# SpeakSpot

SpeakSpot은 말하는 내용에 맞춰 PDF의 페이지와 본문 블록을 찾아주는 실시간 음성 탐색 서비스입니다.
문서를 열고 설명을 시작하면 관련 블록이 강조되고, 발화에 맞춰 페이지가 이동합니다.
강의 자료를 설명하거나 발표 내용을 문서와 함께 확인할 때 사용할 수 있습니다.

## 사용 방법

1. 프로젝트 루트의 **SpeakSpot.cmd**를 실행합니다.
2. 브라우저에서 **PDF 업로드**를 눌러 문서를 선택합니다. 파일 크기는 최대 **40 MB**입니다.
3. 문서 준비가 끝나면 **음성 인식**을 누르고 마이크 사용을 허용합니다.
4. PDF의 내용을 말하면 뷰어 위에 발화가 표시되고 관련 블록이 강조됩니다.
5. 음성 인식을 끝내려면 **인식 중지**를 누릅니다.

PDF는 위아래 스크롤이나 페이지 이동 버튼으로 살펴볼 수 있습니다.
**발화 따라가기**는 기본으로 켜져 있으며, 끄면 음성 인식과 검색을 계속하면서 자동 페이지 이동만 멈춥니다.
다시 켜면 최근 매칭 페이지로 이동합니다.
**뷰어 페이지로 보정**은 기본으로 꺼져 있습니다. 켜면 지금 보고 있는 PDF 페이지를 검색 기준으로 맞춥니다.
이후 스크롤·페이지 버튼·방향키로 이동할 때도 검색 기준을 보정합니다. 보정 후 다음 발화부터 해당 페이지를 기준으로 탐색합니다.
자동 페이지 이동을 멈추고 살펴보려면 **발화 따라가기**를 끄면 됩니다.
**블럭 경계 표시**를 켜면 문서에서 추출한 블록의 범위를 점선으로 확인할 수 있습니다.

## 설치

Python **3.11 이상**, Node.js **22.12 이상**, pnpm이 필요합니다.
아래 명령은 프로젝트 루트에서 Windows PowerShell로 실행합니다.

```powershell
python -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r .\backend\requirements.txt

$env:HF_HUB_DISABLE_XET = "1"
.\backend\.venv\Scripts\python.exe .\backend\pdf.py

pnpm --dir frontend install
```

`backend/pdf.py`는 PDF 레이아웃·표 구조·한국어/영어 OCR·E5 모델을 준비합니다.
첫 준비에는 인터넷 연결이 필요하며, 다운로드한 모델은 로컬 캐시에서 재사용합니다.
모델 학습이나 API 키 등록은 필요하지 않습니다. CPU에서도 실행할 수 있습니다.

## 실행

**SpeakSpot.cmd**를 더블클릭하면 백엔드와 프론트 서버 창이 각각 열리고 브라우저가 실행됩니다.
로그와 오류는 각 서버 창에서 확인합니다. 창을 닫으면 해당 서버가 종료됩니다.
이미 실행 중인 SpeakSpot 서버는 재사용합니다.

| 구성 | 주소 |
| --- | --- |
| 웹 화면 | http://127.0.0.1:5173 |
| 백엔드 | http://127.0.0.1:8000 |

브라우저를 열지 않고 서버 창만 실행하려면 `python start.py --no-browser`를 사용합니다.

수동 실행은 프로젝트 루트에서 터미널을 각각 열어 진행합니다.

```powershell
# 백엔드
.\backend\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000
```

```powershell
# 프론트
pnpm --dir frontend dev
```

## 동작 방식

- **음성 인식:** 브라우저의 Web Speech API로 한국어 발화를 텍스트로 변환합니다. Chrome과 마이크가 필요합니다.
- **PDF 분석:** Docling으로 제목·본문·목록·표와 읽기 순서를 분석하고, 이미지 속 한국어·영어 텍스트는 OCR로 추출합니다.
- **문서 탐색:** KIWI로 추출한 최신 명사 8개를 슬라이딩 큐에 두고, E5-small로 문서 용어와 비교합니다.
  블록·페이지 점수와 페이지 이동 조건을 함께 적용하며, 단어 비교 결과는 캐시에서 재사용합니다.

검색은 로컬 Python 백엔드에서 수행합니다. 탐색 범위는 발화 기준 페이지의 **앞뒤 5페이지**입니다.
기준은 처음에 1페이지에서 시작하며 발화 매칭에 따라 갱신됩니다. **뷰어 페이지로 보정**이 켜져 있으면 수동 탐색 위치도 기준에 반영됩니다.
E5는 단어 비교에 사용되며 음성 인식 문장을 교정하지 않습니다.

PDF 분석은 업로드할 때 수행합니다. 페이지가 많거나 스캔 이미지가 많은 문서는 준비 시간이 더 걸릴 수 있습니다.
PDF는 서버 메모리에서 처리하므로 백엔드를 재시작하면 문서를 다시 업로드해야 합니다.
브라우저 음성 인식은 로컬 검색과 별개이며, 크롬의 일반적인 온라인 인식에서는 음성이 인식 서버로 전송됩니다.

## 프로젝트 구조

| 파일 | 역할 |
| --- | --- |
| `backend/main.py` | 문서 업로드와 발화 검색 API |
| `backend/pdf.py` | PDF 구조 분석, OCR, 강조 좌표와 모델 준비 |
| `backend/search.py` | 명사 추출, E5 단어 비교와 슬라이딩 큐 검색 |
| `backend/requirements.txt` | Python 의존성 |
| `frontend/src/App.jsx` | 음성 인식, PDF 업로드와 뷰어 |
| `frontend/src/style.css` | 화면 스타일 |
| `frontend/vite.config.js` | 개발 서버와 백엔드 프록시 |
| `start.py`, `SpeakSpot.cmd` | 서버 실행 |
