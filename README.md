# SpeakSpot

SpeakSpot은 말하는 내용에 맞춰 PDF의 페이지와 본문 블록을 찾아주는 로컬 웹앱입니다.
강의나 발표 중에 관련 본문을 강조하고, 발화 따라가기를 켜면 페이지도 자동으로 이동합니다.

## 사용 방법

1. 프로젝트 루트의 **SpeakSpot.cmd**를 실행합니다.
2. 브라우저에서 **PDF 업로드**로 최대 **40 MB**의 PDF를 열거나 **최근 저장한 PDF**에서 문서를 선택합니다.
3. 상단에 **PDF 분석 중** 또는 **PDF 탐색 준비 중**이 표시됩니다. 준비가 끝나면 마이크 버튼을 누르고 마이크 사용을 허용합니다.
4. PDF의 내용을 말하면 뷰어 위에 발화가 표시되고 관련 블록이 강조됩니다.
5. 음성 인식을 끝내려면 **인식 중지**를 누릅니다.

PDF는 스크롤이나 오른쪽의 페이지 이동 버튼으로 살펴볼 수 있습니다. **더보기**에서 **발화 따라가기**와 **블럭 경계 표시**를 켤 수 있습니다.
**발화 따라가기**는 기본으로 꺼져 있습니다. 켜면 최근 발화 위치로 이동한 뒤 새 발화를 계속 따라갑니다.
**블럭 경계 표시**를 켜면 추출된 본문 블록의 범위가 점선으로 표시됩니다.

| 조작 | 동작 |
| --- | --- |
| **Space** 짧게 | 최근 발화 위치로 한 번 이동합니다. |
| **Space** 길게 | 최근 발화 위치로 이동한 뒤 누르는 동안 새 발화를 따라갑니다. 키를 떼면 더보기의 발화 따라가기 설정으로 돌아갑니다. |
| **C** | 지금 보고 있는 페이지를 발화 검색의 기준으로 맞춥니다. |
| **Shift+클릭** | 클릭한 PDF 위치에 필기를 추가합니다. |

더보기에서도 단축키를 확인할 수 있습니다. 필기 입력창에서는 Space와 C를 글자 입력에 사용합니다.

### PDF와 필기 저장

- PDF를 처음 열면 원본이 브라우저에 자동 저장됩니다. **최근 저장한 PDF**에서 다시 열면 저장한 페이지와 필기가 복원됩니다.
- 필기를 작성한 뒤 **Enter**를 누르거나 필기 아이콘을 클릭하면 접히면서 자동 저장됩니다. 아이콘을 드래그해 옮기거나 오른쪽 클릭 메뉴에서 필기를 삭제할 수 있습니다.
- 더보기의 **저장**은 보고 있는 페이지와 필기를 기록합니다. **나가기**는 첫 화면으로 돌아갑니다.
- 최근 목록의 휴지통은 해당 PDF의 브라우저 저장본과 필기를 지웁니다. 서버가 연결되어 있으면 서버에 저장한 검색 색인도 지웁니다.

## 설치

Python **3.11 이상**, Node.js **22.12 이상**, pnpm이 필요합니다.
아래 명령은 프로젝트 루트에서 Windows PowerShell로 실행합니다.

```powershell
python -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r .\backend\requirements.txt

$env:HF_HUB_DISABLE_XET = "1"
.\backend\.venv\Scripts\python.exe .\backend\pdf.py

pnpm --dir frontend install
```

`backend/pdf.py`는 PDF 레이아웃·표 구조·한국어/영어 OCR과 BGE-M3 모델을 준비합니다.
첫 준비에는 인터넷 연결이 필요합니다. 문서 검색에는 로컬 캐시의 BGE-M3 모델이 필요합니다.
모델 학습이나 API 키 등록은 필요하지 않습니다. CPU에서도 실행할 수 있습니다.

## 실행

**SpeakSpot.cmd**를 더블클릭하면 백엔드와 프론트 서버 창이 각각 열리고 브라우저가 실행됩니다.
로그와 오류는 각 서버 창에서 확인합니다. 창을 닫으면 해당 서버가 종료됩니다.
이미 실행 중인 SpeakSpot 서버는 재사용합니다.
다른 브랜치에서 실행한 백엔드 창이 있으면 닫은 뒤 다시 실행해야 현재 브랜치의 검색 코드가 적용됩니다.

| 구성 | 주소 |
| --- | --- |
| 웹 화면 | http://127.0.0.1:5173 |
| 백엔드 | http://127.0.0.1:8000 |

브라우저를 열지 않고 서버 창만 실행하려면 `python start.py --no-browser`를 사용합니다.

수동 실행은 프로젝트 루트에서 터미널을 각각 열어 진행합니다.

```powershell
# 백엔드
.\backend\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000
```

```powershell
# 프론트
pnpm --dir frontend dev
```

## 동작 방식

- **음성 인식:** 브라우저의 Web Speech API로 한국어 발화를 텍스트로 변환합니다. Chrome과 마이크가 필요합니다.
- **PDF 분석:** Docling으로 강조 좌표와 OCR 블록을 추출합니다. PyMuPDF에서 읽은 제목, 글꼴, 도식의 텍스트와 숫자를 검색 단서로 추가합니다.
  PDF에 한글·영문 또는 약어·원어가 함께 표기돼 있으면 그 문서의 용어 단서로 등록합니다.
- **페이지 탐색:** BGE-M3와 KIWI로 후보를 찾고, 새 제목과 본문의 고유 표현이나 도식에 반복되는 숫자로 페이지 전환을 확인합니다.
  제목이 같은 페이지나 중간 페이지를 건너뛰는 전환에는 추가 단서를 사용합니다.
- **블록 강조:** 같은 항목에 속하는 블록의 점수와 최근 발화에서 확인한 용어를 함께 반영해 현재 페이지에서 블록 하나를 강조합니다.

검색은 로컬 Python 백엔드에서 수행합니다. 탐색 범위는 발화 기준 페이지의 **앞뒤 3페이지**입니다.
새 PDF의 검색 기준은 1페이지에서 시작하며 발화 매칭과 페이지 초기화에 따라 갱신됩니다.

PDF 원본, 필기, 마지막으로 저장한 페이지는 브라우저의 IndexedDB에 저장합니다.
완성된 검색 색인은 서버의 `backend/.cache/analysis/`에 PDF별로 보관합니다. 서버를 다시 켜도 저장된 색인에서 페이지별 용어 목록, 검색 벡터, 블록 좌표를 읽어 바로 복원합니다.
서버에 색인이 없으면 브라우저에 저장된 분석 결과를 가져옵니다. 두 곳 모두에 결과가 없으면 PDF를 한 번 분석합니다.
백엔드를 켜면 발화 검색 모델을 백그라운드에서 미리 불러옵니다. 모델과 색인이 준비되면 마이크 버튼이 표시됩니다.
브라우저 음성 인식은 로컬 검색과 별개이며, 크롬의 일반적인 온라인 인식에서는 음성이 인식 서버로 전송됩니다.

## 프로젝트 구조

| 파일 | 역할 |
| --- | --- |
| `backend/main.py` | 문서 업로드와 발화 검색 API |
| `backend/analysis_cache.py` | 완성된 검색 색인의 서버 저장과 복원 |
| `backend/analysis_snapshot.py` | 브라우저 저장본과 검색 분석 데이터 교환 |
| `backend/pdf.py` | PDF 읽기와 OCR, 제목·도식 배치, 강조 좌표, 모델 준비 |
| `backend/text_index.py` | 형태소 분석, 문서별 용어와 도식 단서 색인, 검색 점수 정규화 |
| `backend/search.py` | 발화 순서와 문맥 처리, 임베딩 검색, 블록 강조 |
| `backend/lecture_matching.py` | 페이지 전환 확인과 페이지 안의 블록 추적 |
| `backend/requirements.txt` | Python 의존성 |
| `frontend/src/App.jsx` | 음성 인식, PDF 업로드와 뷰어 |
| `frontend/src/savedDocuments.js` | 브라우저에서 PDF, 필기, 마지막 페이지와 분석 결과 저장 |
| `frontend/src/style.css` | 화면 스타일 |
| `frontend/vite.config.js` | 개발 서버와 백엔드 프록시 |
| `start.py`, `SpeakSpot.cmd` | 서버 실행 |
