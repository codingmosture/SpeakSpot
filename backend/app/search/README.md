# Sliding queue

기본 `sliding_queue`는 임베딩 모델 없이 동작하며 E5-small을 선택해 단어 비교에 사용할 수 있다. 큐에는 기존과 같이
최근 `sliding_window_words`개(기본 8개) 명사·영문 용어를 유지하며, 미확정 STT 가설은
누적하지 않고 교체한다. 확정 이벤트 중복 방지는 `SearchEngine`이 담당한다.

검색 비교에는 Kiwi의 일반명사(NNG)·고유명사(NNP)와 영문 용어/식별자만 사용합니다.
조사·어미·동사·형용사·부사·대명사·의존명사·단독 숫자는 제외하며, `종속성`처럼
명사에 붙은 접미사는 합쳐 보존합니다. `SQL2003`, `employee_id` 같은 식별자의
숫자·기호는 용어 일부로 유지합니다. PDF 본문/키워드와 발화에 같은 필터를 적용하고,
실시간 매칭 패널에도 실제 비교에 사용하는 명사 큐를 표시합니다. 제외된 말은 큐를 차지하거나
기존 명사를 밀어내지 않습니다. SQL 한글 발음이나 영어 오인식을 고정 사전으로 치환하지
않으며, STT 자막·타임라인과 PDF 원문은 그대로 유지합니다.

새 발화와 전체 큐의 점수를 2:1로 반영해, 긴 이전 문장이 짧은 새 주제를
가리지 않도록 한다. 이전 큐의 단어만 일치하는 블록은 제외한다.
페이지 문맥 75%, 개별 블록 일치 25%로 후보를 비교한 뒤 기존 페이지 유지
보너스, 뒤로 이동 감점, 최소 점수, 전환 마진을 적용한다. 여러 블록으로
나뉜 설명도 함께 판단하되 결과의 하이라이트는 실제 블록을 가리킨다.

현재 페이지 ±`local_radius_pages` 범위만 탐색한다. 범위 밖으로 자동 복구하는
전역 검색은 수행하지 않는다. 형태소 분석은 OCR/STT의 잘못 인식된 고유명사나
누락된 단어를 복원하지 않으며, 짧은 미확정 발화는 여전히 모호할 수 있다.

실시간 추적에는 별도의 기준 페이지를 둔다. 인접 페이지로의 이동에는 현재
페이지에 없던 용어 2개 또는 새로운 구문 일치가 필요하다. 한 단어만으로도
주변에서 유일한 대상을 식별할 수 있으면 즉시 이동할 수 있다. `값`, `표현`,
`여부`처럼 일반적인 설명만으로는 새 주제로 판단하지 않는다. 인접 이동을
확인하면 미확정 발화 중에도 기준을 갱신하므로 긴 발화에서도 진행할 수 있다.
비인접 후보는 거리 감점 후 0.65 이상의 점수 또는 다른 페이지보다 명확한
우위(최소 0.12, 전환 마진 설정이 더 크면 그 값)가 필요하다. 불명확한 중간
인식이 연이어 탐색 범위를 이동시키는 현상을 줄이기 위한 기준이다.

최신 발화 원문에 `후반부`, `나중에`, `앞에서`, `지난 시간`, `다음 시간` 같은 회고·예고
표현이 있으면 그 언급으로 다른 페이지에 이동하지 않는다. 실제 새 주제가
이어지면 해당 표현이 최신 발화에서 사라지고 다시 탐색한다. 주변 슬라이드의 내용이
비슷하거나 목차와 본문이 같은 용어를 사용하면 전환이 늦을 수 있다.

화면 이동은 점수 계산과 별도로 확인한다. `그다음에`, `그래서`, `음` 같은 연결어는
검색 근거에서 제외한다. 새 페이지 후보는 연속된 가설에서 내용이 추가되며 유지되거나,
두 개 이상의 내용 단어를 포함한 발화가 확정된 경우에 이동한다. 같은 가설의 반복과
서로 다른 발화 ID는 이동 확인으로 누적하지 않는다. 문서에서 유일하게 식별되고
점수가 높은 단일 키워드는 즉시 이동할 수 있다. 따라서 자막·큐 갱신 주기는 유지하면서
페이지 전환에 한 번의 추가 인식 갱신이 필요할 수 있다.

브라우저 어댑터는 여러 미확정 결과를 한 가설로 합치고, 같은 결과와 확정 이벤트를
중복 전송하지 않는다. 인식기가 재시작하면 결과 인덱스에 새 발화 ID를 부여한다.
백엔드도 확정된 발화의 늦은 중간 결과를 무시해 이전 MATCH가 화면에 재적용되지 않게 한다.


## 슬라이딩 큐의 E5 단어 비교

개발자 메뉴에서 알고리즘 **슬라이딩 큐**, 모델 **E5-small · 단어 의미 비교**를
선택하고 설정을 적용한다. 기본값은 기존 모델 없음이며, 선택 시에만 E5를 로딩한다.
큐·페이지·블록 점수를 문장 벡터로 교체하지 않는다. 기존 단어 일치 함수가
`기존 표기/조사 일치 OR E5 코사인 유사도 ≥ word_match_threshold`를 확인한다.
기준 기본값은 0.90이며 개발자 메뉴에서 조정한다. 낮출수록 다른 단어까지
일치할 수 있다. 동일 표기는 임계값과 관계없이 기존처럼 일치한다.

형태소로 추출한 PDF의 고유 단어 벡터를 미리 생성·문서별 캐시하고, 큐에 새로
등장한 단어만 배치 인코딩한다. 발화·문서 양쪽에 `query:`를 붙여 대칭 비교한다.
이는 [E5 모델 문서](https://huggingface.co/intfloat/multilingual-e5-small#faq)의
의미 유사도 입력 형식이다. 문서/발화 원문을 다른 단어로 치환하거나 고정 사전을
추가하지 않는다. 블록 문장 전체의 `rank()`는 이 경로에서 호출하지 않는다.

단어 커버리지, IDF, 최신 발화 2:1 가중치, 페이지 문맥 75%와 블록 25%, 탐색 반경과
페이지 전환 확인 로직을 유지한다. 새 주제·전환·앞부분 일치 검사도 같은 단어
비교기를 사용하므로 표기가 다르다는 이유만으로 의미 일치 후보를 배제하지 않는다.
미확정 발화 교체·중복 확정 방지·미리보기 상태 복원은 기존 방식 그대로다.
API 설정 예: `{"search_strategy":"sliding_queue","search_model":"e5-small","word_match_threshold":0.90}`.
추가 의존성/API 키는 없으며 기존 E5 캐시를 재사용한다. 짧거나 다의적인 단어,
동의어·반의어는 모델이 잘못 비교할 수 있으므로 실제 문서로 기준을 조정한다.


## 증분 큐 갱신

새 형태소가 들어올 때만 모델 단어 비교와 블록/페이지 일치·앞부분 일치·IDF를
계산한다. 일치하지 않은 결과도 캐시하므로 같은 가설이나 무관한 단어가 반복돼도
모델 비교를 다시 수행하지 않는다. 캐시는 세션별로 최대 512개를 보관하되 현재
큐에 필요한 항목은 유지한다. 같은 명사가 나중에 다시 등장하면 캐시가 남아 있을
때 재사용하고, 퇴출된 경우에만 다시 비교한다.

최근 큐와 최신 발화의 단어 개수 변화를 따로 추적한다. 새 단어의 기여분은 더하고,
빠진 단어는 빼며, 반복 횟수만 바뀌면 그 가중치 차이만 반영한다. 미확정 가설이
수정되거나 확정돼도 같은 원칙을 적용한다. 명사 큐, 기존 점수 공식, 페이지 전환
조건과 모델 미사용 동작은 유지한다. 미리보기는 큐·집계·캐시를 복원하고 초기화는
모두 비운다. 서버 STT는 사용하지 않는다.
