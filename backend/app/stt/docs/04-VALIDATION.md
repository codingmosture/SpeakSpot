# 검증 기록과 팀 통합 범위

## 확인된 내용

| 근거 | 확인 범위 |
|---|---|
| 2026-11-11 자동 테스트 37개 통과 | PCM 보존·시각·캐시·중단·WebSocket·schema·Origin·CER, Google SDK 요청과 CLOVA 로컬 모의 gRPC |
| 기존 6.016초 한국어 WAV 실제 실행 | tiny/CPU int8 파일 인식, 실제 시간 간격 WebSocket 전송, 결과 3개와 정상 종료 |
| 기존 PC 마이크 3초 실행 | 마이크 입력, 결과 조회, 자동 종료, 모델 재사용 |
| 2026-11-11 사용자 피드백 | 인증 설정 후 테스트가 정상 동작한다고 사용자 확인 |

자동 테스트는 사용자 클라우드 계정의 권한·요금·한국어 인식 품질을 검증하지 않습니다.
사용자 정상 동작 확인도 정답 기반 정확도 평가나 장시간 성능 보증과는 구분합니다.
이번 문서 정리는 실행 코드를 변경하지 않았으며 테스트 수는 직전 코드 검증 기록입니다.

## 측정값을 해석하는 방법

- 파일 평가에서 tiny RTF 약 0.173을 한 번 관찰했습니다. PC와 음성에 따라 달라집니다.
- 실제 음성의 정답 파일이 없어 해당 실행의 CER는 측정하지 않았습니다.
- 10분 모의 입력 테스트는 합성 PCM을 빠르게 넣는 시각/버퍼 검사입니다. 실제 10분 강의 테스트가 아닙니다.
- 클라우드 API의 순수 처리시간/RTF는 측정하지 않으므로 null입니다. 결과 지연에는 네트워크와 발화 확정 대기가 포함됩니다.

## 팀에 전달할 때

1. `api/stt*.py`, `schemas/stt_models.py`, `stt/`의 소스/테스트/문서를 리뷰합니다.
2. `schemas/models.py`의 STTSegment 호환 import를 확인하고 다른 팀 모델은 유지합니다.
3. 실습용 `api/stt_app.py`를 기존 앱 전체와 교체하지 않습니다. 필요한 기능만 팀 진입점에 등록합니다.
4. `/live/*`는 서버 PC 마이크를 여는 개발용 API이므로 공개 사용자 경로에 그대로 노출하지 않습니다.
5. `.venv`, `.models`, 샘플 음성, 실험 결과, 인증 파일, __pycache__는 커밋하지 않습니다.
6. 실제 강의 녹음/정답으로 CER와 지연을 비교하고 10분 이상 연속 테스트합니다.

현재는 STT 모듈 리뷰와 통합을 진행할 수 있는 단계입니다. 전체 팀 서비스 완료 상태를 의미하지 않습니다.
